# nanobot voice gateway

A small SSE server that wraps the nanobot Python SDK and exposes a
voice-oriented turn protocol for the Home Assistant `nanobot` integration.

The gateway exists because the OpenAI-compatible endpoint only exposes
`delta.content`. Voice clients need to know which text is safe to speak,
when a tool starts, and when a turn was cancelled so partial replies can be
rolled back.

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/health` | Liveness check (compatible with the HA integration) |
| GET | `/v1/voice/capabilities` | Protocol version and feature flags |
| POST | `/v1/voice/turns` | Run one turn and stream SSE events |
| POST | `/v1/voice/turns/{turn_id}/cancel` | Cancel a running turn |

`turn_id` is generated by the client so a cancel request can race the stream
without needing an initial handshake.

## Event stream

```
event: turn.started
data: {"v":1,"type":"turn.started","turn_id":"...","session_key":"...","seq":1,...}

event: segment
data: {"v":1,"type":"segment","seq":2,"index":0,"text":"...","final":false,"lang":"ja"}

event: tool
data: {"v":1,"type":"tool","seq":3,"name":"web_search","state":"started"}

event: turn.completed
data: {"v":1,"type":"turn.completed","seq":4,"content":"...","stop_reason":"completed"}
```

Terminal events are exactly one of `turn.completed`, `turn.cancelled`, or
`error`. Comments (`: ping`) keep the connection alive during long tool calls.

## Run

```bash
python -m pip install "nanobot-voice-gateway @ git+https://github.com/yyamanoi1222/home-assistant-nanobot#subdirectory=voice_gateway"
nanobot-voice-gateway --port 8900
```

The gateway reuses `~/.nanobot/config.json` unless `--config` is given.

## Configuration

| Flag | Env | Default |
| --- | --- | --- |
| `--host` | `NANOBOT_VOICE_HOST` | `127.0.0.1` |
| `--port` | `NANOBOT_VOICE_PORT` | `8900` |
| `--api-key` | `NANOBOT_VOICE_API_KEY` | unset |
| `--config` | `NANOBOT_CONFIG` | SDK default |
| `--workspace` | `NANOBOT_VOICE_WORKSPACE` | SDK default |
| `--model-preset` | `NANOBOT_VOICE_MODEL_PRESET` | unset |
| `--max-concurrent-turns` | `NANOBOT_VOICE_MAX_TURNS` | `4` |
| `--cancel-timeout` | `NANOBOT_VOICE_CANCEL_TIMEOUT` | `5.0` |
| `--heartbeat-interval` | `NANOBOT_VOICE_HEARTBEAT` | `15.0` |
| `--turn-ttl` | `NANOBOT_VOICE_TURN_TTL` | `300.0` |

## Notes

- Tool side effects cannot be rolled back. Run the gateway against a
  restricted workspace when it is reachable from voice devices.
- `ephemeral: true` turns skip snapshots and rollback entirely.
- A client disconnect cancels the turn and still rolls back session history.
